# DECTRA - Detektiv Investigatsiyalar Platformasi

Premium detektiv investigatsiya ishlarini xarid qilish va o'ynash uchun zamonaviy veb-platforma.

## Xususiyatlar

- 🎭 Qorong'u kinematik atmosfera
- 📱 Mobile-birinchi responsive dizayn
- 🔍 Immersiv investigatsiya interfeysi
- 💎 Glassmorphism dizayn
- 🌟 Smooth animatsiyalar
- 🔐 Foydalanuvchi autentifikatsiyasi
- 💳 To'lov interfeysi
- 🗂️ Ishlar katalogi va filtrlash

## O'rnatish

```bash
npm install
npm run dev
```

## Qurilish

```bash
npm run build
```

## Foydalanish

```bash
npm run preview
```
